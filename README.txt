БРОДИ ПО ГОРОДУ — ПРОТОТИП

Распакуйте архив и откройте папку brodi в VS Code. Запустите index.html через расширение Live Server. Либо выполните в терминале: python -m http.server 8001 и откройте http://localhost:8001/.

Чтобы открыть профиль, нажмите кнопку «Профиль» в правом верхнем углу.

Карта условная. Задания, партнёрства, бутсы и награды демонстрационные. Данные хранятся локально в браузере; при смене браузера или адреса сервера прогресс может не отображаться.
