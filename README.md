# Ходи Броди — прототип городской афиши и заданий

Статический прототип (HTML + CSS + ванильный JS) главной страницы и личного профиля.

## Запуск

```bash
python3 -m http.server 8000
# http://localhost:8000/index.html
```

Либо откройте папку в VS Code и запустите `index.html` через Live Server.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: hero, карта с заданиями, подборки, обмен бутс, лавка, «как играть» |
| `styles.css` | Дизайн-система (токены, кнопки, шапка, карточки) и стили главной |
| `profile.html` | Профиль: обзор, задания, места, бутсы, путь, интересы, лавка, отзывы |
| `profile.css` | Раскладка личного кабинета; палитра и формы наследуются из `styles.css` |
| `app.js` | Логика главной: фильтры, выбор задания, избранное, обмен |
| `profile.js` | Логика профиля: вкладки, цель накопления, покупки, достижения |
| `data.js` | Демо-каталог мест |

## Дизайн-система

Все цвета заданы токенами в `:root` файла `styles.css` и взяты из исходной палитры проекта
(`#8080d8`, `#7272ca`, `#aeaef6`, `#f0efff`, `#ede800`, `#111113`, `#262634` и нейтрали).
Новые оттенки не добавлялись — только полупрозрачные состояния hover/active/focus.

- Базовый размер текста — 16px, минимальный — 12px.
- Контраст текста: `--muted` 7.3:1 и `--purple-text` 5.9:1 на белом (WCAG AA).
- Крупные поверхности (hero, обмен бутс, секция карты) используют `--purple-ink`/`--ink`,
  потому что белый текст на исходном `#8080d8` даёт 3.5:1 — этого мало для мелкого текста.
- Радиусы, отступы и тени — переменные `--r-*`, `--gutter`, `--section-y`, `--shadow-*`.
- Адаптив: 1120 / 980 / 760 / 420px, есть поддержка `prefers-reduced-motion`.

## Данные

Прогресс хранится в `localStorage` (`brodi-new-concept-v2`, `brodi-profile-v1`) и не связан
с аккаунтом на официальном сайте. Задания, награды, билеты и мерч — демонстрационные.
Картинки мест и логотип лежат в `assets/`; при их отсутствии интерфейс подставляет
монограмму места и текстовый логотип вместо битых изображений.
