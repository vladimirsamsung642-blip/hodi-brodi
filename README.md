# Ходи Броди — прототип городской афиши и заданий

Статический прототип (HTML + CSS + ванильный JS) главной страницы и личного профиля.

## Запуск

```bash
python3 serve.py
# http://localhost:8000/index.html
```

`serve.py` — тонкая обёртка над `http.server`: отдаёт корректные MIME для `.webp/.svg/.ico/.woff2`,
запрещает кеширование HTML/CSS/JS (правки видны сразу) и кеширует `assets/` на сутки.
Порт меняется переменной `PORT`.

Либо откройте папку в VS Code и запустите `index.html` через Live Server.
Важно: при открытии по `file://` браузер не загрузит `data.js` — нужен любой HTTP-сервер.

## Структура

| Файл | Назначение |
|------|------------|
| `index.html` | Главная: hero с поиском, афиша событий, карта с заданиями, подборки, обмен бутс, лавка |
| `styles.css` | Дизайн-система (токены, кнопки, шапка, карточки) и стили главной |
| `profile.html` | Профиль: обзор, задания, места, бутсы, путь, интересы, лавка, отзывы |
| `profile.css` | Раскладка личного кабинета; палитра и формы наследуются из `styles.css` |
| `app.js` | Логика главной: афиша (период, категории, избранное, `.ics`), поиск, карта, задания, обмен |
| `profile.js` | Логика профиля: вкладки, цель накопления, покупки, достижения |
| `eventsData.js` | Реальные места и события с hodi-brodi.ru: фото, адреса, цены, координаты |
| `data.js` | Приводит данные источника к форме приложения (награды, флаги, мета) |
| `map.js` | Яндекс.Карты: метки, кластеры, кастомные балуны, связь с карточками |
| `serve.py` | Локальный сервер превью: MIME, заголовки кеширования, порт из `PORT` |
| `assets/` | Логотип и favicon (SVG), резервные иллюстрации мест 960×600 |

## Дизайн-система

Все цвета заданы токенами в `:root` файла `styles.css` и взяты из исходной палитры проекта
(`#8080d8`, `#7272ca`, `#aeaef6`, `#f0efff`, `#ede800`, `#111113`, `#262634` и нейтрали).
Новые оттенки не добавлялись — только полупрозрачные состояния hover/active/focus.

- Базовый размер текста — 16px, минимальный — 12px.
- Контраст текста: `--muted` 7.3:1 и `--purple-text` 5.9:1 на белом (WCAG AA).
- Крупные поверхности (hero, обмен бутс, секция карты) используют `--purple-ink`/`--ink`,
  потому что белый текст на исходном `#8080d8` даёт 3.5:1 — этого мало для мелкого текста.
- Радиусы, отступы и тени — переменные `--r-*`, `--gutter`, `--section-y`, `--shadow-*`.
- Адаптив: 1120 / 980 / 760 / 420px, есть поддержка `prefers-reduced-motion`.

## Афиша и поиск

- Периоды: сегодня / завтра / выходные / неделя; фильтры «Бесплатно», «С детьми», «Избранное», категории со счётчиками.
- Поиск в hero: события и места, подсказки, стрелки и `Enter`, `/` — фокус, `Escape` — очистка.
- Любое событие выгружается в календарь файлом `.ics` (RFC 5545, строки ≤ 75 октетов).
- Избранные события и фильтры хранятся в `localStorage` под ключом `brodi-afisha-v1`.
- «Купить билет» — демонстрационная метка с ценой: платёж и бэкенд не подключены.

## Данные

Прогресс хранится в `localStorage` (`brodi-new-concept-v2`, `brodi-profile-v1`) и не связан
с аккаунтом на официальном сайте. Задания, награды, билеты и мерч — демонстрационные.
Картинки мест и логотип лежат в `assets/`; при их отсутствии интерфейс подставляет
монограмму места и текстовый логотип вместо битых изображений.

## Данные и карта

Каталог собран с боевого сайта `hodi-brodi.ru`: 16 событий и 9 мест
Тольятти и Жигулёвска — реальные названия, цены, площадки, адреса и фотографии.
Даты событий фиксированные (22–25 ноября 2026), поэтому при демонстрации
позже этого окна афиша покажет пустой период.

### Фотографии

Ссылки ведут на `hodi-brodi.ru/media/...` и грузятся браузером напрямую,
с `referrerpolicy="no-referrer"` — чтобы не попасть под хотлинк-защиту.
Если картинка не пришла, срабатывает `onerror`: контейнер получает
брендированный градиент и монограмму названия, пропорции сохраняются,
вёрстка не едет. Логика — `bindImageFallbacks()` в `app.js`.

### Яндекс.Карты

Инициализация в `map.js`, ключ — `ac0dd8aa-6124-4239-89b1-31db39165c0a`.
Метки строятся по координатам из `eventsData.js`, сгруппированы кластером,
клик открывает кастомный балун с фото, названием, временем, адресом
и ссылкой на карточку.

**Ключ привязан к домену.** Для `localhost` и `127.0.0.1` Яндекс проверку
не делает, поэтому локально карта работает сразу. На новом домене
(в том числе на превью `*.e2b.app`) добавьте его в кабинет разработчика
Яндекс.Карт. Пока домена нет в списке, вместо карты показывается
объяснение и список точек со ссылками — страница не ломается.
